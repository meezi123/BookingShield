# Project Scope

## ML model

Predict hotel booking cancellation risk.

## Web application

Provide a responsive booking-risk form, risk result, revenue-at-risk estimate, and recommended action.

## AI feature

Draft a human-reviewable guest confirmation or recovery message based on booking risk and hotel policy.

## Non-goal

The public dataset is used to demonstrate a product prototype. A real hotel would require its own historical booking data and model retraining.
